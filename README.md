# 电信经营决策 Agent

## 项目简介
本项目为电信经营决策实训交付物，包含可运行的决策页面、决策引擎与技能说明。

## 目录结构
- `index.html` 页面入口
- `engine.js` 决策引擎
- `skill/SKILL.md` 技能说明
- `evidence/` 运行记录与复盘
- `tools/run-tests.js` 测试脚本

## 运行方式
用浏览器打开 `index.html` 即可。

## 测试
```
node tools/run-tests.js
```
